# Frontend Documentation

Store Markdown documentation for the client application in this folder.
Backend documentation remains in `server/docs`.

## Documentation

- [Component documentation](./component-doc/README.md) contains one page for
  each component in `client/src/components`.
- [Common UI Components](./common-components.md) documents the reusable
  components in `client/src/components/common`.
- [Form Components](./forms.md) documents the reusable form controls in
  `client/src/components/forms`.
