# `SessionCard`

Source: [`SessionCard.jsx`](../../src/components/common/SessionCard.jsx)

Displays a session or workshop in a list with its title, type, time range,
optional location and description, and optional child actions.

## Props

- `session`: session record with `title`, `type`, `startTime`, `endTime`, and
  optional `location` and `description`.
- `eventName`: optional event label.
- `children`: optional actions rendered below the session details.
