# `ExhibitorLogo`

Source: [`ExhibitorLogo.jsx`](../../src/components/common/ExhibitorLogo.jsx)

Displays an exhibitor logo using the shared file URL helper. If there is no
logo, it displays a briefcase icon instead.

## Props

- `logo`: optional stored logo path.
- `companyName`: used to create the image alternative text.
- `size`: size class suffix; defaults to `"md"` (cards). `"lg"` is used on
  larger profile views.
