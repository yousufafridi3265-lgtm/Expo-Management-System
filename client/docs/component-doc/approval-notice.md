# `ApprovalNotice`

Source: [`ApprovalNotice.jsx`](../../src/components/exhibitor/ApprovalNotice.jsx)

Shows an exhibitor's approval status and a matching explanation. Approved
profiles also get a link to their public exhibitor page.

## Props

- `profile`: exhibitor record with `_id` and `approvalStatus`.

The status text covers pending, approved, and rejected states.
